16// Moves encoding off the caller's thread. Frames are validated on the caller's
17// thread, then handed through a bounded queue to one encoder thread, which is
18// the only thread calling the wrapped backend while a destination is open.
19//
20// Overload policy is to wait: when the queue is full, writeFrame() blocks until
21// the encoder takes a frame, so no frame is dropped. A queue slot is reserved
22// before a frame is copied, so the writer holds at most capacity frames in the
23// queue plus the one being encoded, whichever overload is used. An encoder
24// failure is sticky for the destination: queued frames are discarded, blocked
25// producers wake, and every later writeFrame() and the closing release() return
26// false.
27//
28// release() and the destructor join the encoder thread, so they wait for a
29// backend call in progress however long it takes; there is no cancellation.
